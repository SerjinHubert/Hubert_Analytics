# 📊 Call Center Performance Dashboard (Excel Project)

This project showcases an interactive and fully automated **Excel Data Analysis Dashboard** built using real-world call center metrics.  
It demonstrates strong skills in **data cleaning, formulas, pivot tables, visualization, and dashboard design.**

---

## 🚀 Key Features

- 📞 **Call volume analysis by city, representative, and time**
- 🎯 **KPI summary cards** (Total calls, ratings, amount, call duration, satisfaction)
- 📈 **Monthly trend chart**
- 👥 **Gender comparison (Male vs Female)**
- ⭐ **Customer rating distribution**
- 🔁 **Interactive slicers for dynamic filtering**
- 📊 **Pivot Tables & Pivot Charts integration**

---

## 🛠 Skills Demonstrated

| Skill | Used |
|-------|------|
| Excel Formulas | `COUNTIFS`, `SUMIFS`, `AVERAGEIF`, `INDEX`, `IFERROR` |
| Data Cleaning | Table formatting, data validation, named ranges |
| Visualization | KPI cards, charts, conditional formatting |
| Dashboard Design | Layout planning, color theme, alignment |
| Interactivity | Slicers, dynamic charts, linked pivots |
