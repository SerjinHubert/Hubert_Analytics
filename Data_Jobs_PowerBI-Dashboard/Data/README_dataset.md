# Dataset Description

File: `jobs_dataset.csv`

| Column Name | Meaning |
|------------|---------|
| job_title | Job role |
| company | Employer name |
| salary_year_avg | Median yearly salary in USD |
| salary_hour_avg | Median hourly salary in USD |
| work_type | Full-time, part-time, contract etc. |
| remote | Whether job supports remote work |
| location | Country-level job location |
| source | Posting platform (LinkedIn, Indeed, etc.) |

Dataset size: **>25MB**, stored as ZIP or via Git LFS.
